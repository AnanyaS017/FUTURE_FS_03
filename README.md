# Bean & Bliss | Coffee & Kitchen

A modern and responsive café website created for the **Future Interns Full Stack Web Development Internship – Task 3**.

## About the Project

**Bean & Bliss** is a premium modern café website based in **Mangalore, Karnataka**.

The website provides information about the café, menu, offers, gallery, customer reviews, table booking, and contact details.

## Features

* 🏠 Modern Home page
* ☕ Café menu with prices
* 🎁 Special offers
* 🖼️ Café image gallery
* ⭐ Customer reviews
* 📅 Table booking/enquiry form
* 📍 Contact and location information
* 🌙 Dark/Light theme
* 📱 Responsive design for mobile and desktop

## Technologies Used

* HTML
* CSS
* JavaScript
